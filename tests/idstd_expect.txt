# How each project in this repo stands against the REAL ../idstd.
# Read by tests/idstd_real.sh; see that file for what the states mean.
#
#   both       builds with the library and without it
#   needs-std  builds only with it
#   broken     builds only WITHOUT it -- a collision with the library
#   neither    builds neither way (needs --backend or flags)
#
# Every `broken` line is work, not a permitted state: C9 in docs/IDSTD.md.
